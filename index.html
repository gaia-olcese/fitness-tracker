    AI assistant settings

    Enter your personal Gemini API key so you can log workouts and meals by voice or chat using your own Google AI project.

    How to get a Gemini API key:

    FitLog can use a key from your own Google AI project to enable AI logging. Google account eligibility, quotas, and any charges depend on your project and Google's current terms. It is typically free for personal limited use.

    1. Open the Google AI Studio API keys page ↗ and sign in.
    2. Create a key in a project you own, or create a new project and create a key there.
    3. Copy the full key, paste it above, and tap Save API key.
    4. Keep your key private. Google may require project verification or billing setup depending on your project and access tier.
