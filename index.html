    How to get your free Gemini API key:

    FitLog uses your own free Google AI key so you can chat or use voice logging without limits. It takes under 60 seconds:

    1. Open Google AI Studio ↗ and sign in with any Google account.
    2. Click the "Create API key" button near the top right or on the sidebar.
    3. Select "Create API key in new project".
    4. Copy the code that pops up (it starts with AIzaSy...), paste it in the box above, and tap Save API Key!
